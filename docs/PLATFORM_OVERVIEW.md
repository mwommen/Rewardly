# Rewardly Platform Overview

Rewardly is financial decision trust infrastructure.

## Platform Services

- Payment Decision Engine
- Financial Intent Platform
- Merchant Intelligence
- Benefit Registry
- Wallet Intelligence
- Purchase Context
- Confidence Scoring
- Recommendation Validation
- Trust Infrastructure
- Identity and Cloud Sync

## Permanent Boundary

Rewardly owns trust. Clients own experience.

The platform produces recommendations, explanations, evidence, confidence, versions, audit references, and replay results. Clients collect context, present results, and preserve user agency.

## Public API Surface

- Payment decisions
- Financial intents
- Merchant knowledge
- User wallet and cloud data
- Trust records and replay

## Client Applications

- Chrome extension: real-time checkout surface
- Mobile app: first-party Smart Pay and personal intelligence experience
- Web app: onboarding and demos
- Future SDKs: thin API clients without recommendation logic
