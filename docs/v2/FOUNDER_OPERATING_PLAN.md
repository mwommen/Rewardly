# Founder Operating Plan

## Weekly Priorities

Product: define use cases, API contract, decision-quality standards.
Engineering: engine boundary, tenant model, API, sandbox, security basics.
GTM: build prospect list, conduct interviews, recruit design partners.
Operations: data update process, support workflow, incident basics, docs.

## Founder Time Allocation

- 40 percent customer discovery and design-partner recruitment.
- 35 percent product/API decisions and review.
- 15 percent engineering validation and QA.
- 10 percent operations, legal/security prep.

The founder should not spend all time managing implementation. Customer discovery must run in parallel.

## Weekly Cadence

Monday: sprint priorities and outreach list.
Tuesday-Thursday: interviews plus engineering review.
Friday: decision-quality review, risk update, next-week asks.
