# Rewardly V2 Blueprint

Status: Founding architecture draft
Date: 2026-07-29

Rewardly V2 is the B2B payment-intelligence platform direction. These documents are the source of truth for the pivot from a consumer Chrome extension to an API platform that helps financial products recommend the best way to pay for a specific user and purchase context.
