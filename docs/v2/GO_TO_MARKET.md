# Go To Market

## Founder-Led Motion

Phase 1 problem validation:

- Interview target fintechs.
- Demo current engine and draft API.
- Learn wallet data availability.
- Learn trust/security concerns.
- Learn acceptable response shape and pricing.

Phase 2 design partners:

- Select 2-5 companies.
- Define one use case each.
- Integrate sandbox.
- Review low-confidence decisions weekly.
- Measure activation and decision quality.

Phase 3 paid pilot:

- Add live environment.
- Add support process.
- Define pilot agreement.
- Convert one partner to paid.

Phase 4 repeatability:

- Refine ICP.
- Publish docs.
- Write anonymized case study.
- Improve onboarding.

## First 20 Conversations

Targets: PFM founders/product leads, AI finance app founders, credit-card/rewards site operators, travel rewards apps, loyalty startups.

Ask about current wallet data, payment-advice attempts, user demand, trust concerns, data they can send, integration approval, budget, and success metric.

Proceed signal: 3+ companies agree to sandbox integration or design-partner pilot.
Pivot signal: interest exists only as free feature.
Stop signal: no reachable customer has wallet data or urgency.
