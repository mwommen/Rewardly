# Product Definition

## What Rewardly Is

Rewardly is an API-based payment intelligence platform that helps financial products select and explain the best payment method for a specific user, wallet, merchant, and purchase context.

## What Rewardly Is Not

Initial V2 is not:

- A payment processor.
- A card issuer.
- A bank.
- A digital wallet.
- A budgeting app.
- A transaction ledger.
- A consumer cashback marketplace.
- A universal merchant-affiliate network.
- A credit bureau.
- A card-number vault.
- A fiduciary financial adviser.
- An automatic payment-routing network.
- A replacement for issuer authorization.
- A Plaid alternative.

## Core Customer Problem

Financial products often have static wallet or card data but cannot reliably answer, "Which payment method should this user use now?" Building this requires card rules, benefit state, merchant intelligence, purchase context, valuations, explanations, and auditability.

## Core End-User Problem

The user owns multiple payment methods but cannot quickly evaluate reward categories, credits, offers, caps, protections, point valuations, merchant eligibility, and purchase context.

## Promise

Rewardly provides estimated payment-decision support: one recommended payment method, explanation, confidence, alternatives, and warnings.

Rewardly does not guarantee issuer reward posting, benefit approval, statement-credit receipt, or payment execution.
