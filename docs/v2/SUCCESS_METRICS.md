# Success Metrics

## Validation

Qualified interviews, confirmed use cases, sandbox requests, design-partner commitments, engineers completing first API call.

## Integration

Time to first valid request, time to first production decision, completion rate, support requests per integration, docs failure points.

## Decision Quality

Decision success rate, unsupported-card rate, unknown-merchant rate, low-confidence rate, no-decision rate, rule-error rate, partner-disputed decisions, feedback rate, helpful rate.

## Commercial

Active design partners, paid pilots, MRR, decisions per partner, expansion, retention, gross margin, support burden.

## Product Impact

Recommendation interaction rate, card-switch intent, estimated incremental value, engagement, retention, session depth, conversion.

Avoid vanity metrics such as raw page views or installed extension count.
